# Видео: «Как древние люди понимали, что можно есть?» — сборка в Remotion

Тестовая сборка сцены 1 (~81 с) в плоском 2D-стиле: SVG-персонажи, субтитры с подсветкой ключевых слов, экранные метки, счётчик сумки, звуковые эффекты.

## Запуск (Windows / WSL2)

```bash
cd video
npm install
npm run studio    # предпросмотр и правки в браузере
npm run render    # экспорт в out/scene01_test.mp4
```

## Структура

| Файл | Что внутри |
|---|---|
| `src/timeline.ts` | Фразы озвучки с таймкодами, добавленные паузы, оценка времени слов, границы кадров |
| `src/characters.tsx` | Герой и мальчишка (SVG по частям: руки, мимика, моргание, ходьба, силуэт) |
| `src/world.tsx` | Фон, куст, дерево, птица, камера, плашки, выноски, облачка мыслей, иконки |
| `src/overlay.tsx` | Субтитры и счётчик сумки |
| `src/Scene01.tsx` | Постановка кадров 6–17 и звук |
| `public/sfx/` | Синтезированные эффекты (FFmpeg): свист, поп, вжух, щебет, ветер, дзынь |

Исходник озвучки — `../assets/source/audio/scene01_vo.mp3` (не изменяется; `npm run assets` копирует его в `public/vo/`).

## Как править

- **Сдвинуть паузу** — `GAPS` в `src/timeline.ts`.
- **Границы кадров** — `SHOTS` в `src/timeline.ts` (исходное время аудио).
- **Подсветка слов в субтитрах** — массив `KEY` в `src/overlay.tsx`.
- **Время пословно оценено по длине слов.** Для точной синхронизации экспортируйте из ElevenLabs таймкоды слов (озвучка с timestamps или Forced Alignment) и замените `WORDS`.
